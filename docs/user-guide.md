# MiDuo 1.0.2 使用说明
1. 从官网或正式 Release 安装，先直接打开桌面试用，不必先设置为默认桌面。
2. 需要完整设置与编辑时，在官网获取授权码并到 MiDuo 输入，首次激活需联网。
3. 在设置中按需选择默认启动器、开启无障碍和恢复全面屏手势。授权不能解除系统限制，部分 HyperOS 版本可能要求切回系统桌面。
4. 本机无线调试的配对教程见 [官网](https://mymiduo.xyz/guide/wireless-debugging/)。不要向他人发送配对码。普通安装试用不需要 ADB；可选手势配置可能需要无线调试。
5. 长按桌面空白处进入缩略编辑；壁纸和小组件入口保留在编辑区。图标/文件夹/小组件长按编辑需授权。系统组件可能另需绑定确认。
6. 文件夹采用横向 3×3 分页。内外屏布局切换时不要重复添加同一组件。
7. 外屏 StandBy 默认关闭，设置中开启后横置进入；内屏不使用 StandBy。开合动画默认开启，可在设置关闭。
8. MiDuo 已为默认桌面时可用“恢复系统桌面”；也可以通过系统默认应用设置切换。先保留布局与授权，不要为解决问题直接卸载或清数据。

天气为示例数据。部分组件点击、信号读数和动效仍待完善。出现问题请附机型、系统版本、MiDuo 版本、内外屏及复现步骤；遮挡授权码和个人信息。
旧测试包与正式包可能签名不同，无法覆盖时先联系作者，不要自行强制清除已有数据。

English: Install and try Home first. Activate before changing settings or editing. Default Home, accessibility and gesture setup depend on Android/HyperOS permission rules. StandBy is cover-only and opt-in; fold animation can be disabled. Never share pairing codes, activation codes or private order links. See the website for the current setup guide.
